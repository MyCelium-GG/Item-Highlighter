# ItemHighlighter (Forge)

Hold an item, give it a color, spot it instantly. Tinted hotbar and offhand
slots plus a colored `★ Highlighted` tooltip line for any item type you
highlight with `/hl #RRGGBB` (`/hl clear` removes it, `/hl list` shows all).

- Per-item-type highlights with custom colors, persisted across restarts

Requires **Mycel**. Needs Forge 66.0.9+, Minecraft 26.3, Java 25.
