<img src="https://raw.githubusercontent.com/MyCelium-GG/Item-Highlighter/20324060cf68/docs/img/banners/the-menu-box.svg" alt="Press H (rebindable under Controls, Inventory) to open it: over an item in any inventory for that item, or in the world for the held item. /hl opens it too. Your highlighted items are on the left, and typing in the search box finds any item, so you can mark things you don't have yet. Picking a color from the palette, the picker or a hex code highlights the item right away." width="100%">

![Commands](https://raw.githubusercontent.com/MyCelium-GG/Item-Highlighter/20324060cf68/docs/img/banners/commands.svg)

<img src="https://raw.githubusercontent.com/MyCelium-GG/Item-Highlighter/20324060cf68/docs/img/banners/commands-box.svg" alt="Command: /hl Hold the item and type (client command, no permissions needed): /hl #ff55aa — highlights the held item type in that color (also &#ff55aa; legacy codes like /hl &a or /hl §a work too; anything after the color, e.g. /hl &a&lMy Axe, is ignored). /hl — opens the menu. /hl clear — removes the held item type's highlight. /hl list — lists every highlighted item with a color swatch." width="100%">
